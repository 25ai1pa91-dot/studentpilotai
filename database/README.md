# StudentPilot AI — Database Migrations, Seeds & Graph Models

This directory contains database DDL scripts, migration files, sample content seeders, and Neo4j graph cypher queries.

---

## 📁 Subdirectory Layout

- `/migrations`: PostgreSQL versioned SQL schema migrations.
- `/seeds`: Content taxonomy, baseline quiz seeds, and domain skill seeds.
- `/graph`: Neo4j Cypher scripts for establishing CS skill dependency edges.
