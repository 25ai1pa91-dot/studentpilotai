# StudentPilot AI

# Ultimate Figma Master Prompt

### (Version 1.0)

**Target**

Design one of the world's best AI-powered education platforms.

Not just beautiful.

Not just modern.

Not just animated.

It must feel like a product built by the same people who designed Apple, Linear, Notion, Arc Browser and Perplexity.

The design should be memorable.

It should become StudentPilot's identity.

If someone sees a screenshot without the logo they should still recognize

"This is StudentPilot."

---

# CORE DESIGN PHILOSOPHY

The UI is not decoration.

The UI is a learning tool.

Every pixel must reduce confusion.

Every interaction must increase confidence.

Every screen must answer exactly one important question.

The product should never overwhelm students.

It should never feel like a dashboard.

It should never feel like an LMS.

It should never feel like ChatGPT.

# FINAL QUALITY BAR

Before considering any screen complete, ask:

* Would Apple ship this?
* Would Linear approve this hierarchy?
* Would Notion approve this readability?
* Would Perplexity approve this AI experience?
* Would a first-year college student instantly understand it?
* Can a frontend engineer build it without redesigning it?
* Does every pixel have a purpose?

If the answer to any is **No**, redesign it before presenting the result.

# 🚀 Mera suggestion (ye bahut important hai)

**Is prompt ko ek baar mein mat bhejna.**

Agar tum Claude ya Figma AI ko **itna bada prompt** doge, wo context limit ki wajah se quality lose kar dega.

**Best workflow:**

1. **Prompt 1:** Design Philosophy + Design System
2. **Prompt 2:** Information Architecture + User Flows
3. **Prompt 3:** Low-Fidelity Wireframes
4. **Prompt 4:** High-Fidelity UI (screen by screen)
5. **Prompt 5:** Component Library + Tokens
6. **Prompt 6:** React + Tailwind + shadcn implementation

Is approach se output ki quality ek hi mega prompt dene se kaafi better hoti hai.
