# StudentPilot AI — AI Engine & Intelligence Models

This directory contains the AI context assembly pipelines, LLM integration wrappers, prompt templates, vector memory storage scripts, and automated evaluation metrics.

---

## 📁 Subdirectory Layout

- `/prompts`: System prompt definitions for AI Mentor, Code Evaluator, and Diagnostic Analyzer.
- `/vector_store`: Qdrant vector index client, embedding generators (`text-embedding-3-small`), and semantic search helpers.
- `/intelligence`: Placement Readiness scoring functions, Ebbinghaus decay calculators, and skill gap mapping functions.
